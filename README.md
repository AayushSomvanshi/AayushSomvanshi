## 🚀 Featured Projects

### 🧑‍🍳 [Friendly Neighbourhood Chef](https://github.com/AayushSomvanshi/Friendly-Neighbourhood-Chef) — *Live on Render*
> AI-powered recipe assistant that generates meal suggestions from ingredients you already have at home.

- Integrated **Google Gemini API** with a Flask backend for real-time conversational responses
- Supports follow-up modifications ("make it spicier", "no onions") via context-aware prompting
- Deployed live at [neighbourhood-chef.onrender.com](https://neighbourhood-chef.onrender.com)

**Stack:** Python · Flask · Google Gemini API · HTML/CSS · Render

### 🅿️ [Smart Parking Management System](https://github.com/AayushSomvanshi/Smart-Parking-Management-System)
> Real-time parking slot detection system using computer vision — detects availability across 60+ slots with live dashboard updates.

- Used **OpenCV** for video frame analysis and pixel-based occupancy detection
- Built a **Flask-SocketIO** backend to stream live updates with low latency
- Interactive dashboard shows slot availability in real time across multiple zones

**Stack:** Python · OpenCV · CVZone · Flask · SocketIO · HTML/CSS
